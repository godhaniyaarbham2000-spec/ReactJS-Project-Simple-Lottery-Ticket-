# 🎟️ React Lottery Game Project

A simple and fun **React + Vite Lottery Game** where a random 3-digit ticket is generated and the winner is decided based on the sum of digits. If the sum equals 15, the user wins the lottery.

---

## 🚀 Features

* 🎲 Generate random lottery ticket (3-digit)
* 🔢 Calculate sum of digits automatically
* 🎉 Win condition (sum = 15)
* ❌ Lose message for other results
* ⚡ Instant UI updates using React state
* 🎨 Clean and simple UI design

---

## 🛠️ Tech Stack

* React.js (useState Hook)
* Vite (Fast build tool)
* JavaScript (ES6+)
* CSS3 (Custom styling)

## ⚙️ How to Run This Project

### 1. Clone the repository
```
git clone https://github.com/godhaniyaarbham2000-spec/ReactJS-Project-Simple-Lottery-Ticket.git
```

### 2. Move to project folder
```
cd ReactJS-Project-Simple-Lottery-Ticket
```

### 3. Install dependencies
```
npm install
```

### 4. Start development server
```
npm run dev
```

## 💡 Usage

- Click **Get New Ticket** button  
- A random 3-digit ticket will generate  
- Sum of digits is calculated automatically  
- If sum = 15 → 🎉 You Win  
- Else → ❌ Try Again
